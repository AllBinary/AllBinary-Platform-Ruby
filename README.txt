                             AllBinary Platform Ruby

What is it?

This repository contains code generated by the AllBinary Platform for ArkTS and 
React Native support in Ruby.  This repo is used to allow developers 
to skip the Ruby code generation step.

What are some examples game with this Ruby code?

https://allbinary.itch.io (The downloads with "-ts" in the filename are Ruby only builds. Currently that only includes nothing. Also the Ruby builds are not available on Google Play or other stores.)
